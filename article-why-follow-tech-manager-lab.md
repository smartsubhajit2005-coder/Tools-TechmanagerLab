# Why You Should Follow Tech Manager Lab — Website and YouTube Channel

![Tech Manager Lab](site/logo-badge-800-transparent.png)

Tech Manager Lab is built for the person who actually runs IT in a small or mid-sized business. Not the vendor. Not the consultant. The IT manager who has to make the call, explain it to the owner, and live with the result.

The website and the YouTube channel serve one job: make that job easier with specifics, not slogans. This article explains what you get from each, and how the free tools fit into the work.

## What the channel is

The channel — `@techmanagerlab` — publishes practical IT management videos. Each one names a real problem and hands you a working artefact: a scorecard, a checklist, a slide, a script for the meeting with leadership.

Examples of what that means in practice:

- **Vendor negotiation**: the three numbers to have before the call, and what to say when the vendor says "this is final."
- **Helpdesk metrics**: the five that matter, including the one most vendors bury.
- **Total cost of ownership**: why the cheaper quote can be the expensive one, and how to show it in fifteen minutes.
- **Asset lifecycle**: the stage nobody plans for, and what it costs when you skip it.
- **Tech debt**: how to build a case that survives scrutiny instead of losing the vote.
- **Renewal calendar**: start six months early, or pay the price.
- **Chargeback**: who pays for what when it breaks.

Videos run 10–15 minutes in five acts. Faceless, voiced by Christopher (Edge TTS). No hype, no "top 10" filler. The thumbnail tells you the failure case up front; the video gives you the fix.

## What the website is

The website — `techmanagerlab.com` — is where the channel's ideas become reusable. Two parts matter here:

1. **Guides and blog posts** that turn a video into a written reference you can skim at 2 a.m.
2. **A free tools hub** at `techmanagerlab.com/tools/` with 47 browser-based utilities. No account, no upload, nothing leaves your tab.

## The free tools, and what to use them for

Every tool runs in the browser. Input is processed locally; there is no server copy to leak. That matters for an IT manager pasting in configs, tokens, or customer data.

### Document tools

- **Word Counter** — live word, character, and reading-time counts. Use before a board update or a policy doc.
- **Case Converter** — switch text between cases. Use for normalising usernames, hostnames, or ticket titles.
- **Text Diff** — compare two versions of a config or policy and see exactly what changed.
- **DOCX Word Count** — count words inside a Word file without opening it in Word.

### Developer tools

- **JSON Formatter** — format, minify, validate with line-number errors. Use on API responses and config files.
- **Base64** — encode or decode. Use for headers, tokens, and small payloads.
- **URL Encode / Decode** — safe handling of query strings and redirects.
- **JWT Decoder** — read a token's claims locally. Never paste tokens into a website that uploads them.
- **UUID Generator** — bulk UUIDs for asset IDs or test data.
- **Color Converter** — hex, RGB, HSL. Use when matching a vendor's brand or a slide.
- **Regex Tester** — test patterns against sample text with match highlighting.
- **Cron Parser** — turn a cron expression into a human schedule.
- **Calculator** — basic and scientific.
- **URL Shortener (Local)** — localStorage-backed short links, no server.
- **Redirect Page Generator** — generate a client-side redirect HTML file.
- **Hash Generator** — MD5, SHA-1, SHA-256 over text or files.
- **Timestamp Converter** — epoch to date and back, with timezones.

### Network tools

- **IP Subnet Calculator** — mask, range, broadcast, usable hosts. The one you reach for during a VLAN change.
- **DNS Lookup** — resolve A, AAAA, MX, TXT, CNAME records.
- **HTTP Headers** — inspect what a server actually returns.

### Security tools

- **Password Strength** — score and tips for any password.
- **Password Generator** — strong passwords with custom rules.
- **Security Headers** — check HSTS, CSP, X-Frame-Options on a site.
- **Email Header Analyzer** — read routing and auth results from a raw header.
- **SPF / DKIM / DMARC** — validate email authentication records.

### Productivity

- **QR Code Generator / Decoder** — create and read QR codes.
- **Notepad** — a scratchpad that stays in the tab.
- **Carbon Footprint** — annual CO2 estimate.
- **Timezone Converter** — date and time between cities.
- **Unit Converter** — length, weight, temperature, volume, area, speed, and more.
- **Currency Converter** — 180+ currencies, indicative rates.

### Image tools

- **Image Compressor** — shrink file size for email or tickets.
- **Image Resizer** — exact dimensions or percentage.
- **Image Convert** — change format (PNG, JPEG, WebP).
- **Image Cropper** — interactive crop with aspect ratios.
- **Image Metadata Viewer** — see EXIF and other metadata.
- **Image Metadata Remover** — strip metadata before sharing a screenshot.
- **Image to SVG** — vectorise a raster image.

### PDF tools

- **PDF Merge** — combine multiple PDFs into one.
- **PDF Compress** — re-encode pages as compressed images.
- **PDF to Images** — extract pages as PNG or JPEG in a ZIP.
- **PDF Split** — extract pages into separate files.

### Indian finance tools

- **Income Tax Calculator** — India FY 2025-26 new regime.
- **GST Calculator** — slabs 0 / 5 / 18 / 40%.
- **Loan / EMI Calculator** — EMI, interest, total payable.

### Web tools

- **Website Status Checker** — is the site up? HTTP status, time, headers.

## Why follow both

The channel teaches you the decision. The tools let you execute it without installing software or trusting a stranger's server. Together they cut the time between "I need to handle this" and "it's done."

If you manage IT for a business of 20 to 500 people, subscribe to the channel and bookmark the tools page. Use the videos to frame the problem, the tools to do the work, and the guides to write it up afterwards.
