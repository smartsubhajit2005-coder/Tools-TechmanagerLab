JSON Formatter & Validator

Validate, format or minify JSON.

How to use

Paste JSON, then choose Format (2-space indentation) or Minify. Errors show the message from your browser’s JSON parser.

Example

{"a":1,"b":[true,null]} formats to a multi-line version with each key on its own line, and minifies back to a single line.

Limitations

Uses the browser’s JSON parser. Very large integers can lose precision, and error wording differs between browsers. Comments, single quotes, unquoted keys and trailing commas are not valid JSON and are rejected. It does not repair broken JSON.

Privacy

Input is processed by JavaScript on this page and is not sent anywhere by the tool. The page loads a font stylesheet from Google Fonts. See the privacy page.

FAQ

Why does my JSON show as invalid?

Common causes are single quotes instead of double quotes, a trailing comma after the last item, unquoted keys, and comments.

Is my JSON sent to a server?

No. Parsing and formatting run in your browser. Avoid pasting secrets into any online tool unless you have checked how it works.
