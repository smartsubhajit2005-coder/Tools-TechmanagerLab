Case Converter

Switch text between upper, lower, title and sentence case.

How to use

Enter text, choose a case button, then use Copy to copy the result.

Example

“hello WORLD. this is a test” becomes “Hello World. This Is A Test” in title case and “Hello world. This is a test” in sentence case.

Limitations

Title case capitalizes every word, including small words such as “of” and “the”. Sentence case does not recognise names or acronyms, so “NASA” becomes “Nasa”. Results follow Unicode letter rules in your browser.

Privacy

Input is processed by JavaScript on this page and is not sent anywhere by the tool. The page loads a font stylesheet from Google Fonts. See the privacy page.

FAQ

Why are small words capitalized in title case?

This tool applies one simple rule to every word. Style guides differ on small words, so edit the result if you follow a specific guide.

Are line breaks kept?

Yes. Only letter case changes.
