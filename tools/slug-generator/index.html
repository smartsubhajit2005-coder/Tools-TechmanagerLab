Slug Generator

Turn a title into a clean URL slug.

How to use

Type a title. The slug updates as you type; use Copy to copy it.

Example

“Café Menu & Prices (2026)” becomes cafe-menu-prices-2026.

Limitations

Accents are removed. Characters outside Latin letters and digits, such as Bengali or Hindi, are dropped, so titles in those scripts need a manual slug.

Privacy

Input is processed by JavaScript on this page and is not sent anywhere by the tool. The page loads a font stylesheet from Google Fonts. See the privacy page.

FAQ

Why hyphens instead of underscores?

Hyphens are the commonly recommended word separator in URLs. Check the current guidance of the search engines you care about.

Does it shorten long titles?

No. Trim the slug yourself to the key words.
