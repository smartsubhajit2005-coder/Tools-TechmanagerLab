# Editorial QA Checklist (Tech Manager Lab site)

Run before every publish. Tick each item; do not publish with unticked boxes.

- [ ] Sources: every %/₹/stat claim links a primary source with date, or is labeled illustrative
- [ ] Originality: no copied text; quotes attributed with links
- [ ] Usefulness: each page answers one SMB question with a next step
- [ ] Grammar + INR formatting (₹, lakh) verified
- [ ] Links: all internal/external links open correctly (videos: new tab)
- [ ] Accessibility: real alt text, focus-visible, heading order H1→H2→H3
- [ ] Disclosure: affiliate/sponsor noted where relevant; compliance topics carry limits note
- [ ] Audience fit: 20–200 seat firms, no enterprise-only assumptions
- [ ] Meta: unique title + description, canonical set, sitemap entry added
- [ ] CTA: one primary action per page; resource downloads tracked (once analytics lands)
